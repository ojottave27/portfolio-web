Questions

Do you need access to the site?

No. Only the public address, or a staging address. Pages behind a login are listed as "needs login"; send a test account if they should be included.

Is this a legal accessibility or GDPR/LGPD certificate?

No. Automated checks find many problems, not all, and the report says so. It is a technical report you can act on, not a legal opinion.

Can I send it to my client as our own?

Yes. The report carries your agency's name and colour and never mentions me.

Which platforms?

Any site a browser can open: WordPress, WooCommerce, Shopify, Wix, Webflow or hand-coded. Fixes depend on access to the code or the CMS.

What if the site blocks automated checks?

The report says so instead of guessing. Allow the check for the duration of the audit and it runs again.
